# Activity 1 – Step 1: A vague prompt

**Chatbot / model:** Gemini 3.6 Flash <!-- e.g., ChatGPT (GPT-5), Gemini, Claude / เช่น ChatGPT (GPT-5), Gemini, Claude -->

## Prompt

```text
Create tests for a file upload feature
```

## Response

## 1. Functional & Valid Uploads

| ID | Test Case | Description / Action | Expected Result |
| :--- | :--- | :--- | :--- |
| **TC-01** | Single Valid File | Upload a single supported file format (e.g., `.png`, `.pdf`) within size limits. | File uploads successfully; preview/filename displays correctly. |
| **TC-02** | Multiple Valid Files | Select and upload multiple files simultaneously (if batch upload is supported). | All selected files are uploaded and rendered in the list. |
| **TC-03** | Drag-and-Drop Upload | Drag a valid file from the local file manager and drop it into the upload zone. | Upload drops successfully into the zone and completes. |
| **TC-04** | File Preview / Metadata | Upload an image or document and inspect the UI display. | File thumbnail, file name, extension, and file size render correctly. |
| **TC-05** | Cancel / Remove Upload | Click the "Cancel" button during upload or "Remove/Delete" after completion. | Upload stops or file is removed from the server/UI list. |

---

## 2. Validation & Boundary Testing

| ID | Test Case | Description / Action | Expected Result |
| :--- | :--- | :--- | :--- |
| **TC-06** | File Size at Maximum Limit | Upload a file exactly at the maximum allowed size boundary (e.g., 10.0 MB). | File uploads successfully without truncation or error. |
| **TC-07** | File Size Exceeding Limit | Upload a file slightly above the maximum allowed limit (e.g., 10.1 MB). | Upload is blocked; clear error message (e.g., "File exceeds maximum size of 10MB"). |
| **TC-08** | Zero-Byte / Empty File | Upload an empty file (0 KB). | Upload is rejected with an error message indicating empty files are not allowed. |
| **TC-09** | Unsupported Extension | Attempt to upload an disallowed file extension (e.g., `.exe`, `.bat`, `.sh`). | Upload is rejected immediately; error details allowed formats. |
| **TC-10** | Maximum File Count Limit | Attempt to upload more files than the allowed batch limit (e.g., 11 files when max is 10). | System prevents adding extra files or shows a batch size error. |

---

## 3. Security & Vulnerability Testing

| ID | Test Case | Description / Action | Expected Result |
| :--- | :--- | :--- | :--- |
| **TC-11** | File Extension Spoofing | Rename an executable to a valid extension (e.g., `payload.exe` renamed to `payload.png`). | System inspects MIME type / magic bytes and rejects the file. |
| **TC-12** | Malicious Payload / Malware | Upload a file containing a virus signature or test payload (e.g., EICAR anti-malware test file). | Antivirus scanner flags the file, blocks upload, and alerts the user/system. |
| **TC-13** | Path Traversal in Filename | Upload a file named `../../../../etc/passwd` or `..\..\boot.ini`. | System sanitizes the filename before writing to storage. |
| **TC-14** | Double File Extension | Upload a file named `invoice.pdf.exe` or `image.php.jpg`. | System sanitizes or rejects execution of dual extensions. |
| **TC-15** | XSS via Metadata / Name | Upload a file with XSS scripts in its filename (e.g., `<script>alert(1)</script>.png`) or EXIF data. | Filename/metadata is HTML-encoded before rendering in the UI. |

---

## 4. Edge Cases, Network & UX

| ID | Test Case | Description / Action | Expected Result |
| :--- | :--- | :--- | :--- |
| **TC-16** | Special Characters in Filename | Upload files containing spaces, non-ASCII, Unicode, or symbols (`photo #1 (final) & test.png`). | File uploads and parses without corrupting the URL or path. |
| **TC-17** | Network Interruption | Disconnect network mid-upload and reconnect. | Upload displays a clear connection error and provides a retry mechanism. |
| **TC-18** | Large File Concurrent Uploads | Trigger multiple uploads in parallel across multiple tabs or browser instances. | Server processes requests concurrently without session collapse or data bleeding. |
| **TC-19** | Timeout on Slow Connection | Simulate network throttling (3G/Low Bandwidth) during large file uploads. | System handles timeouts gracefully without leaving dangling temporary files. |
